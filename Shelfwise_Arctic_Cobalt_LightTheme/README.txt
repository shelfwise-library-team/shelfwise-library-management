Shelfwise Light Theme: Arctic Slate + Sapphire

This update changes CSS only for light mode. Existing dark-mode CSS, React code,
Java backend, SQLite database, package.json, and fine-rate/member logic are not changed.

Install:
1. Back up D:\Projects\LibraryManagement\frontend\src\styles.css
2. Replace it with frontend\src\styles.css from this package.
3. Save the file and refresh http://localhost:5173 with Ctrl+Shift+R.
4. Check both light and dark modes. If any theme toggle does not work, restore the backup.
